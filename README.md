# GLOBAL TECH INTERNATIONAL CORPORATION

Global Tech International Corporation est une entreprise spécialisée au Burkina Faso qui propose des services en électricité,
automatisation,sécurité incendie,domotique,énergie solaire et réseaux de communication

🌐 **Site en ligne:** https://globaltechbf.com/

## Technologies utilisées

- Laravel
- Filament
- MySQL
- HTML / CSS / JavaScript
- ...

## Fonctionnalités

- Présentation de l'entreprise
- Services
- Réalisations
- Équipe
- Témoignages
- Demande de devis
- Formulaire de contact
- Administration via Filament
